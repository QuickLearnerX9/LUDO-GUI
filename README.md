# 🎲 Ludo Game - Python GUI

A feature-rich desktop implementation of the classic **Ludo** board game built in Python. This project brings the nostalgic tabletop experience to your screen with a clean graphical user interface, a virtual dice system, and vibrant player bases (Red, Green, Yellow, and Blue).

## ✨ Features

* **Interactive GUI:** Custom-styled board grid capturing the classic Ludo layout complete with home yards, safe spots (stars), and colored paths.
* **Multiplayer Support:** Designed for up to 4 players (Red, Green, Yellow, and Blue).
* **Virtual Dice Roller:** Dynamic dice rolling functionality to drive gameplay turns.
* **Lightweight & Fast:** Built using Python with a responsive layout.
